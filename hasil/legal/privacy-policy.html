Privacy Policy: Video Release Tool

Effective date: 27 November 2026

Video Release Tool (the "Tool") is a private tool that the operator of the Money Plumbing and Equator Logic channels uses to publish their own videos to their own Facebook Pages. It is not offered to the public, and only people with a role on the app can use it.

Information the Tool accesses

With the permission of the Page manager, through Meta's APIs:

  • the names and IDs of the Pages the manager can post to, and an access token for the selected Page;
  • the videos the Tool uploads, with their publishing status and links;
  • comments on those videos, read only to check whether the Page has already commented, and comments the Tool posts as the Page.

The Tool does not collect information about viewers or followers. Comment and author identifiers returned by Meta are used for the check above; only the identifier of the Page's own comment is saved.

How the information is used

Only to upload and schedule videos, captions and thumbnails, to post the Page's own comments, and to show the operator the status of each upload. It is not used for advertising, profiling or analytics about other people.

Storage and security

The Tool runs on the operator's own computer. The Page ID and Page access token are stored in a local configuration file. Upload records (video IDs, links, comment ID, dates) are stored in the operator's project files. The App Secret and the short-lived user token entered during setup are used once to obtain the Page token and are not saved by the Tool.

Sharing

The information is not sold or shared with third parties. It is exchanged only with Meta, to perform the actions above.

Retention and data deletion

Information is kept while the operator uses the Tool. To remove it: remove the app under Facebook Settings, Business Integrations (this revokes access), delete the stored token from the configuration file, and delete the upload records. Anyone who believes the Tool holds information about them can ask for deletion using the contact below; requests are answered within 30 days.
